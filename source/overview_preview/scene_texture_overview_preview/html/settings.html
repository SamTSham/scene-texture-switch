Surface descriptions

Optional descriptions improve orientation. Technical material and file names remain unchanged.

The whole principle

Name controlled SketchUp materials Surface01, Surface02, and so on. Every scene chooses one numbered texture state. Replace those images as the design develops; Scene Textures changes them with the scenes while preserving material mapping.

Files

  • PNG is preferred; JPG and JPEG are accepted.
  • PSD and other working files may remain beside the outputs.
  • Use matching pixel dimensions across all states of one surface.
  • 1024 px is the safest shared SketchUp baseline; larger images depend on graphics settings and hardware.

Palette

  • Click a texture number to assign a state without changing scene.
  • Double-click a row to visit that scene.
  • Hover a number for thumbnails; press z or click for a large preview.
  • The circular arrow reloads edited images for the current scene.

Status

  • Black: ready.
  • Red: incomplete.
  • Grey: missing.
  • Amber: conflict or housekeeping warning.

Safety

Migration creates and verifies a separate copy. It never rearranges the only working texture library.

Descriptions are stored with this texture library.
