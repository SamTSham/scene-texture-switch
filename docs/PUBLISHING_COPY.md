## Full listing description

Scene TextureSwitch makes named SketchUp materials show different image files
in different scenes.

It was built for set-design work involving projections, LED surfaces, scenic
graphics, signage, and other images that need to change with scenes. Name the
controlled SketchUp materials `Surface01`, `Surface02`, and so on, then keep a
folder beginning with `textures` beside the saved SketchUp model. Each scene
chooses a numbered picture set.

The compact palette lets you assign picture sets without activating every
scene, see whether all required images are present, preview textures, and jump
to a scene by double-clicking it. PNG, JPG, and JPEG are supported; PNG takes
priority when alternatives coexist. PSD, TIFF, PDF, and other working files
may remain in the same folders and are ignored.

Both scene-organised and surface-organised texture folders are supported, so
existing projects can continue working without forced conversion. The plugin
never resizes, repairs, deletes, or overwrites artwork.

Scene TextureSwitch works locally and has no account, subscription, licence
check, telemetry, or internet requirement. An illustrated guide, starter
textures, and a small working SketchUp example are included.

## Features

- Assign numbered picture sets to every scene from one compact palette.
- Change textures as a scene transition begins.
- Organise pictures by scene or by surface.
- Show ready, incomplete, missing, and conflict states.
- Explain file conflicts and identify which picture is used.
- Preview textures as thumbnails or in a large view.
- Add readable surface descriptions while retaining strict `Surface##` names.
- Keep source artwork and other working files beside exported pictures.
- Work entirely offline.

## Compatibility

Confirmed manually in SketchUp 2026 on macOS.

Windows and additional SketchUp versions have not yet been verified. Reports
from early users are welcome. The included example model is saved in SketchUp
2013 format for broad readability.

## Short announcement

Scene TextureSwitch is a free SketchUp extension for projections, LED
surfaces, scenic graphics, signage, and similar scene-dependent images. Name
materials `Surface01`, `Surface02`, and so on; each SketchUp scene can then use
a numbered picture set from a normal folder beside the model.

The extension includes a compact assignment palette, readiness and conflict
checks, image previews, starter textures, and a working example model. It also
understands the older surface-organised folder layout, so existing projects do
not require conversion.

Version 1.0.0 has been production-tested and is confirmed in SketchUp 2026 on
macOS. Windows and other SketchUp-version reports are especially welcome.
