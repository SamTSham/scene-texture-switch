# Scene TextureSwitch 1.0.0

First public release.

Scene TextureSwitch makes named SketchUp materials show different image files
in different scenes. It is intended for projections, LED surfaces, scenic
graphics, signage, and other scene-dependent images.

## Included

- Automatic texture changes when a scene transition begins.
- Scene-by-scene picture-set assignment from one compact palette.
- Scene-first and surface-first texture-folder organisation.
- Ready, incomplete, missing, and conflict indicators.
- Hover thumbnails and large previews.
- Optional human descriptions for strict `Surface##` material names.
- Finder/Explorer label files for easier folder orientation.
- PNG preference with JPG and JPEG support.
- Working files such as PSD, TIFF, and PDF safely ignored.
- Offline quick guide, illustrated material-naming instructions, starter
  textures, and a SketchUp 2013-format example model.

## Confirmed environment

- SketchUp 2026 on macOS.

The example model is saved in SketchUp 2013 format. Additional SketchUp and
Windows versions will be listed as they are tested.

## Privacy and connectivity

Scene TextureSwitch works locally. It has no account, telemetry, subscription,
licence server, or network requirement.
