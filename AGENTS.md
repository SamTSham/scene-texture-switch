# Scene Texture Switcher working instructions

## Visual communication

When discussing interface layout, spatial organization, thumbnails, menus, panels, or other visual relationships:

- provide a real visual mockup when it materially helps the decision;
- use a generated raster mockup for quick concept exploration;
- use rendered HTML/CSS when exact control placement, typography, spacing, or states matter;
- do not use ASCII boxes or character-drawn wireframes;
- accompany the visual with a short plain-language description of behavior;
- treat the visual as a review artifact, not as proof that the interface has been implemented.

Use text tables only for genuinely tabular data, not as a substitute for spatial interface design.
